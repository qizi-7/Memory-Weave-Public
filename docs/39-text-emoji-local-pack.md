# 本地授权文本表情资源包

Memory Weave 不包含腾讯表情图片。109 个名称仅用于识别准确短代码；资源缺失或加载失败时显示原文，禁止 Unicode 近似替换。名称清单版本 2，对照 xxk8/wechat-emojis 的 109 名称；代码 MIT，图片明确不属于 MIT 授权范围。附代码许可与图片版权例外，未复制图片。

在设置 → 账号与数据库中，确认拥有资源使用权后点击“导入本地资源包”。此入口仅打开用户主动选择的 JSON，不会扫描微信目录、访问 CDN 或向外发送资源。

JSON 格式：`version` 为 1；`source`、`license` 为非空来源及授权说明（各最多 200 字）；`assets` 是最多 109 项的数组。每项包含：

- `name`：完整准确短代码，例如 `[捂脸]`；仅接受版本化清单中的名称，不接受重复名称。
- `mime`：`image/png`、`image/gif` 或 `image/webp`。
- `base64`：图片原始字节的标准 Base64。
- `sha256`：该图片字节的 SHA-256 十六进制摘要。

单张不超过 512 KiB，全部图片不超过 8 MiB；JSON 不超过 12 MB；解码后宽高为 1–512。资源包只含数据，不支持 URL、文件路径、SVG、HTML 或脚本。摘要、文件头、实际解码及名称校验均成功后，以私有文件权限原子保存。错误资源包不替换原有有效资源。

来源与授权声明由用户提供，程序校验不能证明版权许可或图形准确性。使用前应核对 `[捂脸]`、`[呲牙]`、`[微笑]`、`[旺柴]` 的真实微信截图。本次没有取得用户合法提供的原版资源包，图形准确性验收仍未完成。

展示使用图片时，复制操作还原原始短代码；搜索、引用数据、数据库及导出保持原文。导入后已打开页面会刷新，损坏图片回退原文。

# WXGF 时间校准

动态表情的“动画速度”菜单只调整当前消息在本浏览器资料中的 WXGF 转码帧延时，可选 0.5、1、1.5、2、3 倍；1 为原转码延时。此功能不推断微信原始时间轴、不改变原文件、不改变普通 GIF，也不改变全部表情的统一 FPS。校准保留有效帧顺序与循环，不能据此声称恢复原速。原始 HEVC 没有可信 PTS 时仍需以微信客户端人工对照。
